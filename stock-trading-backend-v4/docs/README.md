## 문서 보는 방법

1. **IDE에서**  
   `docs/TRADING-FLOW.md` 파일을 열고 Markdown 미리보기 (VS Code/Cursor: `Ctrl+Shift+V`).

2. **Cursor 채팅에서**  
   질문할 때 `@docs/TRADING-FLOW.md` 로 파일을 첨부하면 AI가 그 내용을 기준으로 답합니다.

3. **GitHub / GitLab**  
   저장소에 push하면 웹에서 Markdown이 렌더링됩니다.

4. **검색**  
   프로젝트 루트에서 `TRADING-FLOW`, `pre-market`, `strategy_signal` 등으로 검색.

루트 [README.md](../README.md) 에도 이 폴더 링크가 있습니다.
